# 弱项训练模块 v2 · 产品与技术设计方案

> 版本：v2.0（2026-11-28）
> 目标：把“做完一场面试 → 看一份报告”升级为“持续定位弱项 → 自适应训练 → 复测验证 → 弱项消弭”的能力提升系统。

---

## 0. 一页纸

### 0.1 旧版的问题

旧版只有一条固定链路：

```
面试报告 → 固定 5 题训练 → 掌握度写回
```

它解决了“报告之后有下一步”，但仍然是**静态题库 + 固定题量 + 单次反馈**：

- 没有能力基线，无法判断用户起点；
- 没有维度视角，用户只看到零散知识点；
- 训练路径固定，难度不随表现变化；
- 答错后没有错题归集和同类题推送；
- 没有阶段目标、成长曲线和“弱项消弭”判定；
- 交互只有文本框，没有利用已有的语音/播报能力。

### 0.2 v2 的核心

```
能力基线测评
  → 五维能力画像（基础 / 项目 / 系统设计 / 表达 / 编码）
  → 弱项定位（维度 → 知识点 → 证据 → 严重度）
  → 自适应训练路径（弱项 / 到期复习 / 拉伸 / 复测）
  → 多模态作答（文字 / 语音 / 代码）
  → 即时反馈 + 同类题举一反三
  → 错题自动归集 → 阶段复测
  → 掌握度与维度分更新 → 弱项消弭判定
  → 下一轮路径重新计算
```

### 0.3 四个特性

| 特性 | 落地方式 |
| --- | --- |
| 自适应 | 按掌握度、到期时间、最近得分、维度缺口动态选题与调难度 |
| 强反馈 | 每题即时评分、命中/遗漏、示范答案、同类题、语音播报 |
| 可追踪 | 知识点掌握度、维度分、日快照、成长曲线、阶段准确率 |
| 高沉浸 | 全屏训练工作台、语音输入、TTS 点评、渐进难度、进度环 |

## 1. 海外产品拆解

| 产品 | 弱项训练相关机制 | 可借鉴点 |
| --- | --- | --- |
| Interviewer.AI | 结构化能力评分卡（沟通、动机、岗位匹配、批判性思维等），按维度给分并生成可解释报告 | 先做**能力维度**，再做题目；报告要能回到维度 |
| Yoodli | 结构、清晰度、简洁度、语速、口头禅等维度评分；“Coach”根据目标推荐下一次练什么，并追踪长期进步 | **个性化训练建议 + 进步可视化**，不是一次性报告 |
| Final Round AI | 每场练习自动 debrief，标出最弱时刻并转成下一轮可重复的 re-drill targets | **报告 → 可执行 drill**，且下一轮接着上一轮弱项 |
| Google Interview Warmup | 语音作答后给 job-related terms、talking points、重复词等洞察，不评分 | **轻量、即时、非评判式反馈**能降低训练压力 |
| Interview Masters | SM-2 间隔重复，按表现动态调整复习频率，把时间放在弱项 | **间隔重复**适合知识点长期记忆 |
| Firecode / Arena | 学习引擎按水平选下一题；卡住时分级提示（提示 → 再提示 → 揭示） | **自适应难度 + 分级提示**，避免一上来就打击 |
| CAT / IRT 研究 | 答对提高能力估计与下一题难度，答错降低；用少量题逼近能力值 | 不需要完整 IRT，但应实现**基于最近表现的难度升降** |

### 1.1 共性结论

1. 头部产品都不是“给一套固定题”，而是**先建模、再选题、再反馈、再追踪**。
2. 维度分与题目级证据必须打通，否则报告无法指导训练。
3. 反馈必须短、具体、可执行；长报告不等于强反馈。
4. 训练效果需要**复测**验证，否则掌握度只是自嗨。
5. 训练必须能持续回到产品里，而不是一次性的页面。

## 2. 产品架构

### 2.1 五维能力模型

| 维度 | 覆盖内容 | 主要来源 |
| --- | --- | --- |
| 基础 `BASICS` | 八股、语言、数据库、网络、操作系统 | 题库 `BASICS`、面试基础题 |
| 项目 `PROJECT` | 简历项目、难点、取舍、结果 | 题库 `PROJECT`、面试项目题 |
| 系统设计 `SYSTEM_DESIGN` | 场景题、架构、容量、权衡 | 题库 `SCENARIO`、系统设计题 |
| 表达 `COMMUNICATION` | 结构、重点、简洁、口头禅 | 面试报告“表达”维度、语音分析 |
| 编码 `CODING` | 手撕代码、边界、复杂度 | 题库 `CODE`、面试编码题 |

知识点通过 `dimension` 归属到维度；维度分 = 该维度下知识点掌握度的加权平均，缺失时用最近一场面试的维度分兜底。

### 2.2 训练阶段

| 阶段 | 触发 | 题量 | 目标 |
| --- | --- | --- | --- |
| `BASELINE` 基线测评 | 新用户 / 无掌握度数据 | 8 | 覆盖五维，建立初始画像 |
| `DAILY` 日常训练 | 首页“开始训练” | 5 | 补最弱 + 复习到期 + 适度拉伸 |
| `RETEST` 阶段复测 | 弱项接近掌握 / 用户主动 | 3 | 验证是否真的会 |
| `MISTAKE` 错题重练 | 错题本 | 3~5 | 清理未解决错题 |

## 5. 自适应算法

### 5.1 目标选择

每日训练 5 题：

1. **最弱 2 题**：`mastery` 最低，优先 `WEAK`；
2. **到期 1 题**：`next_review_at <= now`；
3. **拉伸 1 题**：`mastery` 40~74，难度 +1；
4. **复测 1 题**：最低掌握度知识点，使用未做过的题；
5. 去重：同一知识点最多 2 题，同题 7 天内不重复。

基线 5~8 题：每个维度至少 1 题，剩余 3 题按题库覆盖补足。

### 5.2 难度调整

- 基础难度 2（1~3）。
- 最近 2 题都 ≥4 分：下一题难度 +1（最高 3）。
- 最近 1 题 ≤2 分：下一题难度 -1（最低 1）。
- 拉伸题：在计算难度上再 +1（最高 3）。
- 复测题：使用当前掌握度对应难度（<40 → 1，40~74 → 2，≥75 → 3）。

### 5.3 掌握度

- 观测值 = `score × 20`。
- EMA：`new = round(old × 0.7 + observed × 0.3)`；复测 `0.5 / 0.5`。
- 等级：`<40 WEAK`、`40~74 LEARNING`、`≥75 MASTERED`。
- 复习间隔：`score ≤2 → 1 天`、`=3 → 3 天`、`≥4 → 7 天`；SM-2 的简化版。
- 连续 2 次 ≥4 分：`consecutive_good += 1`；否则清零。

### 5.4 弱项消弭判定

同时满足：

1. `mastery >= 75`；
2. `consecutive_good >= 2`；
3. 最近一次复测 `score >= 4`；
4. 最近 14 天没有新的弱项证据。

满足后写 `eliminated_at`；后续任一题 `score <= 2` 时清除消弭状态并回到 `WEAK`。

### 5.5 维度分

- 维度分 = 该维度下知识点掌握度的加权平均，权重 `1 + log(1 + evidence_count)`。
- 没有知识点数据的维度，用最近一场面试报告的维度分兜底。
- 每次训练结算后重算并写入 `user_dimension_mastery`。
- 每天首次打开仪表盘写入 `training_mastery_snapshot`，用于成长曲线。

## 6. 评估指标

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 基线完成率 | 完成 5~8 题基线 / 触发基线用户 | ≥ 70% |
| 日训练完成率 | 完成 5 题 / 创建训练 | ≥ 60% |
| 训练准确率 | 平均得分 / 5 | ≥ 65% |
| 弱项消弭率 | 14 天内消弭弱项 / 训练弱项 | ≥ 30% |
| 复测通过率 | 复测 ≥4 分 / 复测题 | ≥ 60% |
| 错题解决率 | 已解决错题 / 新增错题 | ≥ 50% |
| 7 日回访率 | 7 日内再次训练用户 / 训练用户 | ≥ 35% |
| 维度提升 | 14 天维度分变化 | ≥ +5 |

成长曲线展示：

- 总体 readiness 折线（近 14/30 天）；
- 五维雷达（当前）；
- 每个弱项知识点的 before/after 与消弭状态；
- 每场训练的准确率、平均分、难度。

## 7. 技术方案

### 7.1 分层

```
Controller
  └─ TrainingController
Service
  ├─ TrainingSessionService      会话生命周期、作答编排
  ├─ AdaptiveTrainingPolicy      选题/难度/阶段策略
  ├─ TrainingFeedbackService     同类题、反馈素材
  ├─ MistakeService              错题归集/解决/重练
  ├─ TrainingAnalyticsService    仪表盘/快照/成长
  ├─ MasteryService              知识点/维度掌握度
  ├─ WeaknessDiagnosisService    面试弱项诊断
  └─ TrainingLlmService          变式题生成/生成题评分
Provider
  ├─ TrainingItemProvider        题源扩展点
  ├─ BankTrainingItemProvider    题库
  └─ AiTrainingItemProvider      AI 变式
Mapper / Entity / DTO
```

### 7.2 数据模型（024 迁移）

在 023 基础上增加：

- `interview_weakness.dimension`
- `user_kp_mastery.dimension / consecutive_good / eliminated_at`
- `user_kp_mastery_log.dimension`
- `training_plan.stage / dimension_focus / policy_json / accuracy / avg_score`
- `training_plan_item.dimension / difficulty / feedback_json / similar_json / mistake_id`
- `training_mistake`：错题本
- `user_dimension_mastery`：五维当前分
- `training_mastery_snapshot`：每日总体/维度快照

### 7.3 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/training/dashboard` | 五维雷达、成长、弱项、错题、到期数 |
| POST | `/api/training/sessions` | `{stage, sourceId?}` 创建基线/日常/复测/错题会话 |
| GET | `/api/training/sessions/{id}` | 会话详情 |
| POST | `/api/training/sessions/{id}/items/{itemId}/answer` | 作答，返回评分、难度、同类题、错题 ID、维度变化 |
| GET | `/api/training/mistakes` | 错题本 |
| POST | `/api/training/mistakes/{id}/retrain` | 错题重练会话 |
| POST | `/api/training/sessions/{id}/abandon` | 放弃 |

旧 `/plans`、`/today` 删除，前端同步切换。

### 7.4 扩展点

- 新题源：实现 `TrainingItemProvider`，不改会话编排。
- 新阶段：扩展 `TrainingStage` + `AdaptiveTrainingPolicy` 分支。
- 新维度：扩展 `TrainingDimension` 与映射，不改表结构。
- 新反馈形态：`TrainingFeedbackService` 增加素材，前端按字段渲染。

### 7.5 删除项

- `TrainingPlanGenerator` 固定 5 题分配逻辑（被 `AdaptiveTrainingPolicy` 替代）。
- `TrainingTargetSlot` 旧的固定槽位语义（改为带难度/角色的自适应槽位）。
- `/api/training/plans`、`/api/training/today` 旧接口。
- `TrainingTodayPage` 旧统计卡片与说明文案（改为仪表盘）。
- `TrainingPlanPage` 旧固定进度/文案（改为沉浸式训练页）。

## 8. 风险与边界

| 风险 | 对策 |
| --- | --- |
| 自适应策略不稳定 | 规则可解释、参数集中配置、先小步升降 |
| 维度映射不准 | 只用题库 type/domain 与报告维度，不强行推断 |
| 错题本膨胀 | 按 KP 聚合，解决后归档，只展示未解决 |
| 语音反馈延迟 | TTS 边收边播；失败时静默降级为文字 |
| 训练疲劳 | 5 题/约 8 分钟，可暂停；难度过高自动降级 |
| 指标造假 | 复测独立题目，同类题不重复；掌握度只由作答驱动 |

## 9. 验收标准

- [ ] 新用户能完成 5~8 题基线并看到五维雷达。
- [ ] 每日训练按“最弱/到期/拉伸/复测”生成 5 题。
- [ ] 连续高分后下一题难度上升，低分后下降。
- [ ] 答错后错题本新增记录，并返回 2 道同类题。
- [ ] 训练结算显示知识点/维度变化与下次复习。
- [ ] 连续 2 次 ≥4 分 + 复测通过后弱项消弭。
- [ ] 仪表盘展示成长曲线与弱项地图。
- [ ] 语音输入与 TTS 点评可用，失败自动降级文字。
